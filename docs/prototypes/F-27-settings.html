F-27 · Settings Prototype

This is a standalone HTML prototype for the Settings panel feature. Click the cog icon in the header to open the panel.

Features demonstrated:

  • AC1 — Settings cog button in header (opens panel on click)
  • AC27.2 — Unit system toggle: Metric / Imperial radio group
  • AC27.3 — Default slider weight (0–100 range, default 50)
  • AC27.4 — "Clear my profile" destructive button
  • AC27.5–6 — Confirmation dialog: Cancel or Confirm

Interaction notes:

  • Click ✕ in the panel header, or click the backdrop, to close
  • Select a unit system — visual feedback only (no persistence in prototype)
  • Drag the Eco/Health weight slider — readouts update in real time
  • Click Clear my profile to see the confirmation dialog
  • On Confirm — toast "Profile cleared" appears
  • On Cancel — dialog closes, nothing happens
