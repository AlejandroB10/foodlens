About FoodLens

FoodLens is a course prototype that scores food on two axes — Health and Eco — and explains its reasoning in one verifiable sentence, never a lecture.

The Creators

Meet the Engineering Team

FoodLens was designed, architected, and built from the ground up by four software engineers as the final prototype for the Human-Computer Interaction course at UIB.

Pau Girón

Dev

software engineer · Palma

"Turning complex multi-objective algorithms into an interface that feels effortless was our biggest UI challenge."

Focused on bridging the gap between raw Nutri/Eco data and a frictionless user experience. Ensured the frontend remained fast, responsive, and accessible.

Soufyane Youbi

Dev

software engineer · Palma

"The architecture had to be resilient. If the backend drops, the UI must gracefully fall back to local data."

Led the system architecture and the KNN recommender engine design. Ensured parity between the Python backend and the vanilla JavaScript fallback to guarantee a bulletproof deployment.

Alejandro Bordón

Dev

software engineer · Palma

"Explainable AI is useless if the user needs a manual to read it. The contrastive sentence is our answer to that."

Worked on the core feature set and the translation of the SHAP waterfall logic into human-readable contrastive explanations, anchoring the AI's reasoning to verified data points.

Alejandro Rodríguez

Dev

software engineer · Palma

"We built an evaluation instrument directly into the prototype so our research data would be as real as possible."

Drove the integration of the research methodology (System Usability Scale and Explanation Satisfaction Scale) into the application flow, allowing seamless in-the-wild testing.

The design is grounded in six WA3 interviews and a thematic analysis: five key insights and seven design hooks. Every screen is checked against the four personas above.

FoodLens is the WA4 prototype of the Transparent Multi-Objective Food Recommendations project at UIB — Master in Intelligent Systems, course 11755 Human-Computer Interaction.

Data sourced from Open Food Facts, an open, collaborative database of food products from around the world. Scores reflect the official Nutri-Score (French public health authority) and Environmental Score (ADEME) methodologies — we consume them, we do not recompute them.

Built with vanilla HTML, CSS and JavaScript. No build step. Open index.html to run.
